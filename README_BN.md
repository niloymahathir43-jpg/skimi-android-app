# SKIMI — নতুন শুরু

এই starter version-এ Home, Chat, AI, Notes এবং Settings-এর প্রাথমিক স্ক্রিন আছে।

## এখনো সংযুক্ত নয়
Login/register, online chat, AI উত্তর, live voice, reels/video upload ও cloud sync এখনো কাজের সার্ভার/API-এর সঙ্গে যুক্ত নয়। এগুলো পরের ধাপে তৈরি ও পরীক্ষা করতে হবে। API key কখনো Android অ্যাপের কোডে রাখবে না।

## APK
GitHub Actions workflow চালিয়ে debug APK তৈরি করার চেষ্টা করা যাবে। Build সফল না হলে Actions-এর error দেখে ঠিক করতে হবে।
